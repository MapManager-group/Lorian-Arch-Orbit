# 渐变配色

按 `P` 打开色轮编辑器，选择底部的“渐变配色”；也可在 Minecraft 按键设置中绑定“打开渐变配色”直接进入，默认未绑定。返回或按 Esc 会保留编辑器原有草稿；从快捷键进入时直接返回游戏。永久色轮的修改只有在编辑器中点击“保存”才会写入配置。

1. 使用上一点／下一点切换节点，可添加、删除节点或反转整个渐变，最多 16 个节点。
2. 每个节点输入六位十六进制颜色，例如 `#E0C9A2`；也可选取上游已收录的方块，或使用手持方块。最后一个节点不需要段长度。
3. 每段数量为 2–128，包含两端；相邻段共享一个节点。默认使用 OkLAB，也可切换 RGB。
4. 选择需要的纹理朝向，以及全部收录方块、上游预设或当前色轮分组作为候选集合。
5. 点击“生成渐变”，预览可分页或滚动。色条显示匹配纹理的颜色；悬停可查看方块与纹理，点击结果可将其设为当前节点。修改输入或筛选后需重新生成。
6. 底部切换应用目标，再点击“应用”：临时色轮、物品栏、新建分组或替换分组。新建／替换仍进入可撤销草稿，确认后在色轮编辑器保存。从快捷键进入时，新建使用一级色轮草稿；替换需要先从编辑器选择分组。

预览提供“隐藏连续重复方块”选项按钮，默认开启。开启后仅合并预览中连续的同种方块，非连续重复保留；关闭后显示全部采样位置，例如单段设置 10 就显示 10 个。切换立即生效，无需重新生成，计数同时显示预览数量和完整生成数量。物品栏和临时色轮始终保留全部生成位置；只有写入永久色轮分组时会去除全部重复物品 ID，并提示去重数量。仅有一种方块的结果可应用到物品栏或临时色轮，但不能新建／替换永久分组。方块节点在符合当前筛选时保留为段端点；若筛选排除了它，则以该颜色寻找符合筛选的最近方块。

## 快速使用与恢复

- **物品栏**：需要创造模式。前 9 个结果按顺序放到快捷栏 1–9，之后放到主物品栏，最多 36 个。只覆盖结果对应的槽位，保留重复方块；超过 36 个会禁用该目标的应用并提示改用临时色轮，不会截断。护甲和副手不参与覆盖。
- **临时色轮**：所有结果按顺序成为临时色轮的位置，不需要手持已有分组中的物品，空手也可打开。保持原有单按一级、双按二级；快速连按色轮键三次（默认 `R`），第三次按住打开临时色轮，滚轮选中后立即将手持物品替换为目标方块，与一级／二级色轮一致；松开仅关闭色轮。相邻短按之间最多间隔 250 毫秒；失去焦点、进入界面或切换世界会关闭色轮，不再额外替换物品；滚轮已完成的替换可通过“恢复物品”回滚。需要创造模式和启用色轮功能。
- **恢复物品**：配色页面顶部提供一键恢复。物品栏应用和临时色轮滚轮切换方块都会在首次覆盖对应槽位前备份其原物品，包含数量、名称、耐久和组件。连续多次应用仍保留最初备份；恢复只写回曾被覆盖的槽位，原为空的槽位恢复为空，然后清除备份。打开渐变配色快捷键后即可快速回滚，也可从 `P` 的配色入口恢复。
- 临时色轮只存于本次游戏进程的内存，不写入配置，重新启动后为空；换世界时可继续使用。物品备份绑定当前玩家实例，断开连接或切换玩家时失效，防止跨玩家恢复。恢复前切换到创造模式。

## 数据与材质

每次启动后台检查上游更新，缓存位于 `config/lorian_arch_orbit/hueblocks/26.2.json`，并提供手动刷新。无缓存且下载失败时配色生成不可用；有效缓存可离线继续使用。损坏或部分下载不会覆盖上一份有效缓存。

数据来自 [HueBlocks](https://github.com/1280px/hueblocks) 的 GitHub Pages：仓库中的 `vueblocks/data/blocksets` 是示例，真实数据由上游部署流程生成。颜色、朝向和调色板完全使用发布的数据，不按当前资源包重新计算。

原版 26.2 模型引用生成了纹理到方块物品的映射，可正确处理远古残骸侧面／顶面和铜方块别名等。只映射能由普通物品表示的基础模型；点亮铜灯等特殊状态纹理以及其他无法映射的纹理不参与生成。界面使用游戏中的物品图标；使用资源包时，物品图标可能与上游原版平均颜色不同。

上游未收录的树叶等方块不会获得猜测颜色。未来新增、尚未包含在本版本映射中的纹理暂不参与生成，需要更新 Mod 的映射。

## 八个内置色系的优化

保持所有原有成员、色系名称、分组 ID 和缺失数据方块的位置。仅调整有上游颜色数据的成员顺序，没有删除或增加成员；同类、同系列预设与用户自定义覆盖不变。

以同一方块的上游侧面颜色平均 OkLAB 值为代表，缺少侧面时使用上游其他面。优化目标是减小有颜色数据的方块之间的累计 OkLAB 欧氏距离。未收录方块没有颜色度量，因此以下数值不能代表包含这些方块的完整视觉效果。

| 色系 | 优化前 | 优化后 | 累计跳变减少 |
|---|---:|---:|---:|
| 红 | 1.421724 | 0.840333 | 40.9% |
| 橙 | 0.334860 | 0.315578 | 5.8% |
| 黄 | 1.069068 | 0.666855 | 37.6% |
| 绿 | 0.681462 | 0.634949 | 6.8% |
| 青蓝 | 1.836144 | 1.398328 | 23.8% |
| 紫／品红／粉 | 2.009330 | 1.618878 | 19.4% |
| 棕 | 1.747420 | 0.829824 | 52.5% |
| 黑／灰／白 | 2.449768 | 1.190065 | 51.4% |

完整原顺序、优化顺序和未收录列表记录在 [优化报告](HUEBLOCKS_PRESET_REPORT.json)。可使用 `scripts/optimize_color_presets.py --jar <26.2原版或合并JAR> --blockdata <上游_blockdata.json>` 重现映射与排序。脚本不读取材质像素，也不会修改其他预设。

配色算法按已核实的功能独立实现，使用标准 sRGB／OkLAB 转换与最近颜色匹配；未复制上游 Vue 源码、图标或 Minecraft 纹理图片。
