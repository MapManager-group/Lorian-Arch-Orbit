# 渐变配色

按 `P` 打开编辑器首页，再选择“渐变配色器”；两页共用编辑器快捷键。右上页面菜单互相切换，右下返回首页；在主编辑页按 Esc 直接退出，有未保存／未应用内容时提示确认。永久色轮的修改只有在色轮编辑器中点击“保存”才写入配置。

1. 点击半透明颜色节点格选择节点，可添加、删除、前移、后移或反转，最多 16 个。每行固定容纳 8 个，更多节点换行，不再提供左右浏览箭头；方块节点显示匹配纹理，底部色条始终保留。
2. 每个节点输入六位十六进制颜色，例如 `#E0C9A2`；也可选取上游已收录的方块，或使用手持方块。最后一个节点不需要段长度。
3. 每段数量为 2–128，输入有效整数即生效，包含两端；相邻段共享一个节点。默认使用 OkLAB，也可切换 RGB。结构／数量变化涉及锁定时先确认清除。
4. 选择需要的纹理朝向，以及全部收录方块、上游预设或当前色轮分组作为候选集合。
5. 点击“生成渐变”，在方块序列或纹理平铺中预览；点击结果进入微调，可替换、锁定、查看面，或明确设为当前节点。修改输入或筛选后需重新生成。
6. 底部切换应用目标，再点击“应用”：临时色轮、物品栏、新建分组或替换分组。新建／替换仍进入可撤销草稿，确认后在色轮编辑器保存。从快捷键进入时，新建使用一级色轮草稿；替换需要先从编辑器选择分组。

“显示”菜单中的隐藏连续重复默认开启，仅合并物品 ID 和纹理均相同的连续候选，不合并同一方块的不同面。微调、纹理平铺及对比显示完整序列。物品栏和临时色轮始终保留全部位置；写入永久分组时按物品 ID 去重并提示。仅有一种方块的结果可应用到物品栏或临时色轮，但不能新建／替换永久分组。方块节点符合当前筛选时保留为端点，否则以该颜色寻找符合条件的候选。

## 面纹理、候选集合与对比

- “选择方块”使用带右侧滚动条的网格，默认展示匹配纹理，可切换物品图标。选中后直接在同页右栏选择顶／底／北／南／东／西；点击“纹理”按钮循环切换该面可行的纹理，底部显示摆放条件。选中内容不随鼠标经过其他方块改变，搜索、滚动与缩放也保留所选面。点击“使用此面”才确认节点或替换；返回不改变结果。小窗口保留精简右栏。“使用手持”和结果微调中的“查看面”仍可进入专用面预览。
- 预览的摆放属性说明如何让该纹理朝向所选方向，不自动摆放或更改世界；尚未收录颜色或被当前筛选排除的面可以查看，不能用于匹配。普通物品应用不保存世界中的朝向状态。
- 在候选菜单选择“编辑候选集合”，点击候选切换纳入／排除；红线表示排除，可搜索后批量排除或全部纳入。已有锁定被排除后显示冲突，必须解除或替换才能生成／应用。
- “显示 → 保留当前结果作对比”保存会话内快照，重新生成后打开“查看结果对比”。两份完整序列同步滚动，快照保留原生成条件。再次保留会替换快照。
- 顶部“方案与候选集”可以导出节点参数或候选筛选为 JSON，保存到 `config/lorian_arch_orbit/gradient-plans/` 或复制到剪贴板；可以从同目录文件或剪贴板导入。候选集合包含基础预设／分组、朝向及排除项。渐变参数还包含节点、段数量及色彩空间，不含生成结果、位置锁定和应用目标。
- 导入参数先确认替换并清除旧结果／锁定；缺失的方块节点会报告并保留其颜色。来源分组或上游预设不存在时拒绝导入。候选集合导入只替换筛选，保留节点与锁定并标记需要生成。未显式导出的参数不会在退出时自动写盘。

## 快速使用与恢复

- **物品栏**：需要创造模式。前 9 个结果按顺序放到快捷栏 1–9，之后放到主物品栏，最多 36 个。只覆盖结果对应的槽位，保留重复方块；超过 36 个会禁用该目标的应用并提示改用临时色轮，不会截断。护甲和副手不参与覆盖。
- **临时色轮**：所有结果按顺序成为临时色轮的位置，不需要手持已有分组中的物品，空手也可打开。保持原有单按一级、双按二级；快速连按色轮键三次（默认 `R`），第三次按住打开临时色轮，滚轮选中后立即将手持物品替换为目标方块，与一级／二级色轮一致；松开仅关闭色轮。相邻短按之间最多间隔 250 毫秒；失去焦点、进入界面或切换世界会关闭色轮，不再额外替换物品；滚轮已完成的替换可通过“恢复物品”回滚。需要创造模式和启用色轮功能。
- **恢复物品**：配色页面左下提供一键恢复。物品栏应用和临时色轮滚轮切换方块都会在首次覆盖对应槽位前备份原物品，包含数量、名称、耐久和组件。连续多次应用仍保留最初备份；恢复只写回曾被覆盖的槽位，原为空的槽位恢复为空，然后清除备份。
- 临时色轮只存于本次游戏进程的内存，不写入配置，重新启动后为空；换世界时可继续使用。物品备份绑定当前玩家实例，断开连接或切换玩家时失效，防止跨玩家恢复。恢复前切换到创造模式。

## 数据与材质

每次启动后台检查上游更新，缓存位于 `config/lorian_arch_orbit/hueblocks/26.2.json`，并提供手动刷新。无缓存且下载失败时配色生成不可用；有效缓存可离线继续使用。损坏或部分下载不会覆盖上一份有效缓存。

颜色和预设来自 [HueBlocks](https://github.com/1280px/hueblocks) 的 GitHub Pages 发布数据，不按当前资源包重新计算。朝向改为使用具体方块的 26.2 模型面，不再直接采用上游按纹理名推断的全局标签。

`scripts/extract_gradient_faces.py --jar <26.2 client.jar>` 从原版 blockstates、模型父链和实际面引用提取 `block_faces.json`，保留状态条件和模型旋转，支持省略命名空间。运行时按注册默认状态匹配，只允许 facing／axis 旋转，不额外引入通电、充能等非默认状态。特殊渲染器及倾斜元素没有普通轴向模型面的部分暂不映射。预览使用当前资源包纹理精灵，但不复现 UV 裁剪、多层透明叠加、光照、群系染色或资源包自定义模型几何。

上游未收录的树叶等方块不会获得猜测颜色；模型已包含但颜色尚未收录的面仍能预览。界面分别显示上游纹理数、映射纹理数、不同物品数和候选数，后两者不相同。新增方块模型需要更新随 Mod 打包的映射；刷新上游数据不重建模型映射。

## 八个内置色系的优化

保持所有原有成员、色系名称、分组 ID 和缺失数据方块的位置。仅调整有上游颜色数据的成员顺序，没有删除或增加成员；同类、同系列预设与用户自定义覆盖不变。

以同一方块的上游侧面颜色平均 OkLAB 值为代表，缺少侧面时使用上游其他面。优化目标是减小有颜色数据的方块之间的累计 OkLAB 欧氏距离。未收录方块没有颜色度量，因此以下数值不能代表包含这些方块的完整视觉效果。

| 色系 | 优化前 | 优化后 | 累计跳变减少 |
|---|---:|---:|---:|
| 红 | 1.421724 | 0.840333 | 40.9% |
| 橙 | 0.334860 | 0.315578 | 5.8% |
| 黄 | 1.069068 | 0.666855 | 37.6% |
| 绿 | 0.681462 | 0.634949 | 6.8% |
| 青蓝 | 1.836144 | 1.398328 | 23.8% |
| 紫／品红／粉 | 2.009330 | 1.618878 | 19.4% |
| 棕 | 1.747420 | 0.829824 | 52.5% |
| 黑／灰／白 | 2.449768 | 1.190065 | 51.4% |

完整原顺序、优化顺序和未收录列表记录在 [优化报告](HUEBLOCKS_PRESET_REPORT.json)。`scripts/optimize_color_presets.py` 和 `texture_blocks.json` 保留用于重现这次历史预设排序，不是当前渐变运行时的面映射；本轮没有重新排列这些预设。

配色算法按已核实的功能独立实现，使用标准 sRGB／OkLAB 转换与最近颜色匹配；未复制上游 Vue 源码、图标或 Minecraft 纹理图片。
