# 本地资源配色实现与验证

日期：2026-10-18。目标：Minecraft 26.3，Fabric 与 NeoForge。修改限于本版本目录；依赖、Java 25 工具链、Mod 身份、配置、距离网络协议、色轮分享格式及既有分组顺序保持不变。

## 实现

- 用当前资源管理器读取方块状态、模型与纹理，动态发现普通原版及 Mod 方块。颜色在线性 sRGB 中按透明度、动画帧持续时间加权，生成 RGB 与 OkLAB。
- 移除运行时 HueBlocks 下载器；保留五个历史候选预设为本地成员表。旧下载缓存不读取、不删除。
- 完整纹理资源标识贯穿节点、筛选、面预览和平铺。渐变方案/候选集合导出为版本 2，继续读取版本 1；旧版 Mod 不支持新导出格式。
- 颜色缓存按有效纹理内容、动画元数据和算法版本匹配；模型映射随资源重载重建。后台计算、完整快照发布与代次令牌防止过期任务覆盖新资源。
- 资源变化时重绑方块节点、保留纯颜色节点并使旧结果失效；缺失节点保留颜色并提示，缺失锁定项显示冲突。对比快照的色条保留原代表颜色。
- 标准 JSON 模型之外的渲染器、自定义加载器、染色面、倾斜元素与不可读纹理有明确边界。整纹理平均不模拟 UV 裁剪、层叠、背景透色、群系、光照或着色器。自定义图集生成/重定向不在本次支持范围内，无法保证这些资源包的颜色与图集预览一致。
- 实现集中在 HueBlocksRuntime、LocalModelFaces、LocalTextureColor、LocalColorCache、LocalHueState、HueResourceId 和渐变界面/方案编解码；两个平台只增加客户端资源重载注册。
